# Cambios

## 1.1.0 — 22 de octubre de 2026

- Ruta de instalación con `npx skills`, sin paquete npm propio.
- Plugin `hotel-marketing` y catálogos `expertoseo` para Claude Code y Codex.
- Manifiesto portable y compatibilidad de Codex, compartiendo la misma carpeta de skills.
- Guía en español con instalación, prefijos de comandos, actualizaciones y desinstalación.
- Validador de manifiestos, versiones, rutas y enlaces, ejecutado también en GitHub Actions.
- Comprobaciones reales de instalación y contenido; las instrucciones de los tres skills conservan los hashes evaluados en la versión 1.0.1.

## 1.0.1 — 22 de octubre de 2026

- Primera versión pública de los tres skills: plan de marketing hotelero, reactivación de huéspedes y seguimiento de solicitudes.
- Instrucciones de descarga, instalación y uso en español para Codex y Claude Code.
- Plantillas, ejemplos ficticios, atribuciones de fuentes y licencia MIT.
- Evaluación en subagentes de Codex: quince escenarios y tres repeticiones posteriores a una corrección.
- Ajuste en seguimiento: mantener aprobaciones y configuración del sistema en notas internas, separadas del mensaje para el huésped.

Claude Code conserva las instrucciones de instalación; su ejecución no fue evaluada.
